# 🚀 Backend Project | TS + Prisma + Postgres

Este é um projeto de backend robusto desenvolvido com **TypeScript**, utilizando **Prisma ORM** para comunicação com o banco de dados **PostgreSQL**.

## 🛠️ Tecnologias Utilizadas

- **Runtime:** [Node.js](https://nodejs.org/)
- **Linguagem:** [TypeScript](https://www.typescriptlang.org/)
- **ORM:** [Prisma](https://www.prisma.io/)
- **Banco de Dados:** [PostgreSQL](https://www.postgresql.org/)
- **Framework:** [ Express ]

## 📋 Pré-requisitos

Antes de iniciar, você precisará ter instalado:
- Node.js (v18 ou superior)
- Docker (opcional, para rodar o Postgres via container)
- Um gerenciador de pacotes (npm, yarn ou pnpm)
